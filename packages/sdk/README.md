# @substructure.ai/sdk

TypeScript SDK for [Substructure](https://github.com/substructureai/substructure), a durable runtime for AI agents.

Includes:

- **Client** — submit work and stream events from your backend or browser.
- **Worker** — host agent handlers as an HTTP endpoint.
- **Middleware** — compose agent behavior (state, message history, tools, LLM routing, sub-agents).

## Install

```sh
npm i @substructure.ai/sdk
```

If you want to run the runtime embedded in your Node.js process (instead of as a separate server), also install [`@substructure.ai/runtime`](https://www.npmjs.com/package/@substructure.ai/runtime).

## Usage

See the [main repository](https://github.com/substructureai/substructure) for documentation and examples.
