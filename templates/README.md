# Templates for substructure.ai

Substructure is an open-source runtime that drives your agent loop over HTTP. It keeps sessions durable across crashes and deploys, retries failed calls, persists state, and streams events to your clients in real time.

Your agent function makes decisions, executes tools and runs on your infrastructure, on whatever platform you already deploy to.

This folder contains a collection of starter templates for building agents with Substructure.
