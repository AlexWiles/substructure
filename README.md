# Substructure

Durable execution for AI agents.

Add agents to your product that survive crashes, resume mid-task, run for as long as they need to, and never lose state.

## Features

- **Your code, your infra** - agent logic lives in your codebase, Substructure handles the durability.
- **Run anywhere** - embed in a process or run as a standalone server
- **Crash recovery** - agents pick up exactly where they left off after crashes, restarts or deployments.
- **Full observability** - inspect, replay, and debug any agent session

## Getting Started

```bash
# Install dependencies
pnpm install

# Run the dashboard
pnpm dev

# Build all packages
pnpm build

# Run tests
pnpm test
```
