# Changelog entry

Write one short sentence for the change. Say what changed, not why or how.

1. Start with a verb in the present tense: `Add`, `Remove`, `Fix`, `Rename`.
2. Keep it to one line. Details live in the code and the commits.
3. Write one entry for related changes that tell one story.
4. Use simple words and short sentences.
