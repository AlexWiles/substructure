`subs` runs agents on your machine and administers a deployment.

```sh
npm install -g @substructure.ai/cli
```

Every command reads `substructure.toml` from the working directory. Pass `-c
<path>` to use another file. See [Config](./220-config.md).

## Commands

| Command | Does |
| --- | --- |
| `subs run` | Run one turn and exit. |
| `subs serve` | Run the engine as an HTTP server. |
| `subs login` / `logout` / `whoami` | Authenticate against a deployment. |
| `subs apply` | Push the file to the deployment. |
| `subs doctor` | Show what the project still needs. |
| `subs projects` | List, show, and delete projects. |
| `subs agents` | List agents and read their signing secrets. |
| `subs llm` | List LLM blocks. Set and delete their keys. |
| `subs keys` | Create and revoke API keys. |
| `subs sessions` | List sessions and stream their events. |
| `subs mcp` | Authorize the connections the file declares. |
| `subs slack connect` | Install the Slack app into a workspace. |
| `subs link` | Pin an org and project in the file. |
| `subs config log` | Show what changed the configuration, and who changed it. |
| `subs open` | Open the project's dashboard. |

## `subs run`

Sends one input, streams the turn, and exits.

```sh
subs run --agent assistant -o pretty "hi"
```

| Flag | Meaning |
| --- | --- |
| `<message>` | The message to send, as a user turn. |
| `--agent` | Which `[agent.<id>]` to run. Falls back to `[run].agent`. |
| `--input` | A [`ClientInput`](./230-protocol.md#client-inputs) in JSON. Its `type` selects submit, resume, or settle. |
| `--session` | Continue a session. Omit it to start one. |
| `-o`, `--output` | `ag-ui` (default), `jsonl`, or `pretty`. |
| `--db` | The SQLite file. |
| `-c` | The project file. |

The CLI checks the agent against the file before it creates a session. After a
turn, it prints the command to continue the session.

## `subs serve`

Runs the engine as an HTTP server.

```sh
subs serve --no-auth
```

| Flag | Meaning |
| --- | --- |
| `--host` | The address to bind. |
| `--port` | The port. |
| `--db` | The SQLite file. |
| `--no-auth` | Serve without client or worker authentication. |
| `--slack-agent <id>` | Also serve a Slack bot for DMs and unnamed channels. |
| `-c` | The project file. |

At startup it logs each declared agent and whether the engine or a worker
decides for it. See [Self-hosting](./180-self-hosting.md).

## `subs login`

```sh
subs login
subs login -c subs.prod.toml     # against the URL that file names
```

Authenticates with the OAuth device flow and stores a token under
`~/.config/substructure`.

Every cloud command takes `--url`. Without it, the command uses the file's
`[remote].url`, then `$SUBS_API_URL`, then the hosted cloud. The CLI stores
credentials per server, so you can be logged in to several deployments.

## `subs apply`

Pushes the file to the deployment. This is the only way to put configuration
into one.

```console
$ subs apply -c subs.prod.toml
Created project support-bot (proj_01hy…) in org_01hx…
Pinned proj_01hy… in subs.prod.toml
Applied 4 changes:
  llm.updated             claude (anthropic)
  agent.updated           support -> https://bot.example.com/agent
  mcp.connection_declared sentry (pending authorization)
  mcp.grant_added         sentry
Signing secrets minted:
  support — `subs agents show support`

Action required:

  Authorize the [mcp.sentry] connection
    subs mcp login sentry -c subs.prod.toml
```

Apply creates the project when the file pins none. It is idempotent. An
unchanged file prints `No changes.` and exits 0.

Apply replaces. An agent, an LLM block, or a Slack channel that is not in the
file is one you removed.

```console
$ subs apply -c subs.prod.toml
Applied 1 changes:
  agent.removed           triage
```

Apply never sends a secret. It strips `api_key_env` and `signing_secret_env`. A
deployment refuses a document that carries one. See [Cloud](./170-cloud.md).

## `subs doctor`

Lists every step nobody has finished.

```console
$ subs doctor -c subs.prod.toml

Action required:

  Connect a Slack workspace
    subs slack connect -c subs.prod.toml

  Set the key for [llm.claude]
    subs llm set-key claude -c subs.prod.toml
```

With a `[remote]`, doctor asks the deployment. Without one, it reads this
machine: the variables that are empty, and the connections with no credential.

```console
$ subs doctor

Action required:

  Set $ANTHROPIC_API_KEY, the key for [llm.claude] (https://console.anthropic.com/settings/keys)
    export ANTHROPIC_API_KEY=...

  Authorize the [mcp.linear] connection
    subs mcp login linear
```

`--json` prints the list as JSON. With nothing left, doctor prints `Nothing to
do.`

## `subs agents`

```console
$ subs agents list
ID       LLM     MODEL                HOSTING                          SECRET
support  -       -                    https://bot.example.com/agent    set
triage   claude  claude-sonnet-4-5    engine                           -

$ subs agents show support          # includes the signing secret
$ subs agents rotate-secret support # owner only
```

An agent exists because the file declares it. There is nothing to create.

## `subs llm`

```console
$ subs llm list
NAME    TYPE       KEY
claude  anthropic  set

$ subs llm set-key claude              # from stdin
$ subs llm set-key claude --env MY_KEY # from an environment variable
$ subs llm delete-key claude
```

A key never appears in the command line. No read returns one.

## `subs keys`

```sh
subs keys create --label backend    # prints the key once, to stdout
subs keys list
subs keys revoke <key-id>
```

Pipe `create` into your secret store. See [Authentication](./190-auth.md).

## `subs sessions`

```sh
subs sessions list
subs sessions events <session-id> --stream
```

See [Events](./240-events.md).

## `subs mcp`

```sh
subs mcp login sentry
subs mcp list
```

`login` opens a browser for consent. See [Connectors](./40-connectors.md).

## `subs slack connect`

```console
$ subs slack connect
Open this URL to add the bot to your workspace:
  https://slack.com/oauth/v2/authorize?…
Opened your browser to install.
Connected Acme (T0123ABC) to org_01hx…
```

If the file names no `[remote]`, the command prints the Socket Mode steps
instead. See [Slack](./130-slack.md).

$ subs config log -c subs.prod.toml

2026-07-30 14:02  alex@…  apply  project.created          support-bot
