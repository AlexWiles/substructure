# Getting started

Substructure lets you focus on agent behavior while the runtime handles
durability and orchestration.

## Install

```bash
npm i -g @substructure.ai/cli
```

## Run your first agent

1. Start the server
2. Start your worker
3. Submit work from a client

## Next steps

- Read the runtime overview
- Learn the worker/server/client model
- Deploy to your preferred serverless platform
